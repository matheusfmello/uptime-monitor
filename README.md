# Uptime Monitor

Basic project that monitors other websites by health checking their services periodically.

This project purpose is mainly educative. I wanted do develop my DevOps knowledge, so I decided to build a simple application that may handle processes of different natures, to enhance my general understanding of end-to-end applications. Also, I decided to develop the application in Go, as I believe it may be enriching to learn a language with a different perspective from the ones I'm used to. 

My main goals are:

* Learn about Go

    * Building APIs
    * Interacting with databases
    * Handle both online requests (RESTful) and batch jobs (Health check)

* Learn about DevOps
    * Develop CI/CD processes
    * Learn about Docker/Kubernetes
    * Learn about deploying applications
